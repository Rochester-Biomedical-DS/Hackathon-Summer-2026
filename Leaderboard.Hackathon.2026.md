***Scoring:***

Submissions are ranked by **accuracy**.

For reference: **accuracy** is the fraction of correctly classified
cells)

**kappa (Cohen’s Kappa)** is a measure of agreement between predicted
and true labels that accounts for agreement expected by chance alone;
ranges from -1 to 1, where 1 is perfect agreement, 0 is like random
guessing given the class distribution, and \< 0 is worse than chance).

**readme_ok**: was there a README.md publicly available for your forked
repo ? (If false, then the repo hasn’t been created yet or the handle is
incorrect)

**message**: Error message if predictions couldn’t be found or parsed.
